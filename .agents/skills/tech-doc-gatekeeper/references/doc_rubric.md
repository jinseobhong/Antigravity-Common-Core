# Technical Documentation Rubric & Quality Standards

본 규격서는 작업자(Worker) 에이전트 또는 테크니컬 라이터가 작성한 기술 문서의 품질을 정량적으로 평가하기 위한 공식 루브릭 기준서입니다.

---

## 1. 정보 완결성 및 명세 충실도 (Completeness & Prerequisites) - 35점

| 평가 항목 | 감점 배점 | 판정 기준 및 위반 정의 |
| :--- | :---: | :--- |
| **플레이스홀더 및 미완성 섹션 잔재**<br>*(Unresolved TBDs & Placeholders)* | **건당 -15점 / Hard Gate** | 문서 본문 내 `TBD`, `TODO`, `[작성 예정]`, `[여기에 설명 추가]`, `Lorem Ipsum` 등 미완성 블록 방치 시 즉시 불합격 |
| **필수 전제조건 및 실행 환경 누락**<br>*(Missing Prerequisites)* | **건당 -10점** | 지원 OS, 최소 언어/런타임 버전(예: Python >= 3.11, Node >= 18), 필수 권한 및 의존 도구 설치 안내 누락 |
| **비정상 흐름 및 에러 처리 가이드 결여**<br>*(Missing Troubleshooting)* | **건당 -10점** | 정상 시나리오만 기술하고, 발생 가능한 런타임 오류 코드, 빈번한 실패 원인, 복구(Troubleshooting) 절차 누락 |
| **데이터 스키마 및 인터페이스 불완전**<br>*(Incomplete Data Schema)* | **건당 -5~-10점** | API 요청/응답 파라미터의 데이터 타입, 필수 여부(Required/Optional), 기본값, 유효 범위 명세 누락 |

---

## 2. 기술적 정확성 및 재현 가능성 (Accuracy & Reproducibility) - 25점

| 평가 항목 | 감점 배점 | 판정 기준 및 위반 정의 |
| :--- | :---: | :--- |
| **실행 불가능한 코드 블록**<br>*(Non-reproducible Code Blocks)* | **건당 -10점 / Hard Gate** | 복사-붙여넣기 시 즉시 실행할 수 없도록 필수 `import`문, 의존성 선언, 변수 정의가 누락된 코드 스니펫 |
| **인터페이스/구현체 불일치**<br>*(API Contract Drift)* | **건당 -10점** | 실제 소스코드와 다른 파라미터 식별자 오기, 폐기된(Deprecated) API 서술, 잘못된 엔드포인트 URL 기술 |
| **언어 식별자 태그 누락**<br>*(Untyped Code Blocks)* | **건당 -5점** | 마크다운 코드 블록(```)에 언어 식별자(```bash, ```python 등)가 누락되어 구문 강조가 적용되지 않음 |
| **깨진 참조 및 앵커 링크**<br>*(Broken References & Links)* | **건당 -5점** | 유효하지 않은 파일 상대 경로 링크 또는 문서 내 존재하지 않는 헤딩 앵커(`#invalid-heading`) 참조 |

---

## 3. 구조적 정합성 및 가독성 (Structure & Hierarchy) - 25점

| 평가 항목 | 감점 배점 | 판정 기준 및 위반 정의 |
| :--- | :---: | :--- |
| **헤딩 계층 구조 파괴**<br>*(Heading Hierarchy Violation)* | **건당 -10점** | H1 바로 다음에 H3이 오거나, 적절한 소제목 분할 없이 100라인 이상의 거대한 단락을 비구조적으로 방치 |
| **주관적/모호한 서술 (위즐 워드)**<br>*(Weasel Words & Ambiguity)* | **건당 -5점** | `"적절하게 설정합니다"`, `"보통 빠릅니다"`, `"알아서 처리됩니다"` 등 엔지니어링 정량성이 결여된 모호한 표현 남발 |
| **구조화된 시각 자료/표 결여**<br>*(Lack of Visuals / Tables)* | **건당 -5점** | 복잡한 생명주기, 데이터 흐름, 다단계 조건 분기를 줄글로만 설명하고 Mermaid 다이어그램이나 비교표 미제공 |

---

## 4. 문서 위생 및 스타일 표준 (Hygiene & Formatting) - 15점

| 평가 항목 | 감점 배점 | 판정 기준 및 위반 정의 |
| :--- | :---: | :--- |
| **도메인 용어 불일치**<br>*(Terminology Inconsistency)* | **건당 -5점** | 동일한 개념/엔터티에 대해 문서 전반에서 상이한 명칭 혼용 (예: '인증 토큰', 'Auth Token', 'JWT'의 무분별한 교차 사용) |
| **마크다운 렌더링 문법 결함**<br>*(Markdown Syntax Defects)* | **건당 -5점** | 테이블 열 구분자 누락으로 인한 렌더링 붕괴, 닫히지 않은 코드 블록 백틱, 비표준 특수문자 깨짐 |
| **편집 및 작성 메모 잔재**<br>*(Editorial Artifacts)* | **건당 -5점** | 작성자 메모, 초안용 주석(`<!-- 작성 필요 -->`), 비활성 마크다운 텍스트 방치 |
