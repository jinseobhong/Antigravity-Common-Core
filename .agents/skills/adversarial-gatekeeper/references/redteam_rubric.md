# Adversarial Red Team Rubric (적대적 감점 루브릭)

본 루브릭은 적대적 감시자가 빌더의 산출물을 100점 만점에서 가차 없이 감점하기 위해 적용하는 엄격한 평가 기준표입니다.

---

## 1. 하드 게이트 (발견 즉시 점수 무관 0점 즉시 퇴출 - Instant HOLD)
1. **시크릿/토큰 유출**: 하드코딩된 API Key, 패스워드, JWT Secret 발견 시.
2. **샌드박스 이탈**: `./sandbox/` 외부의 원본 트리를 오염시키거나 직접 쓰기 시도 시.
3. **스텁 방치**: `TODO`, `FIXME`, `pass`만 박아두고 실제 비즈니스 로직을 구현하지 않은 경우.

---

## 2. 감점 항목 (Deduction Criteria)

| 분류 | 감점 | 적발 사유 |
| :--- | :---: | :--- |
| **요구사항 누락** | **-40점** | 사용자 지시사항(`User Directives`) 중 일부 기능이나 옵션을 임의로 누락/축소 구현한 경우 |
| **예외 은폐** | **-30점** | `except Exception: pass` 등 에러를 로깅 없이 삼켜버리는 방어 로직 발견 시 |
| **경계값 취약** | **-20점** | `None`, 빈 배열, 0, 음수 입력 시 `Uncaught Exception` 또는 크래시 발생 가능성 |
| **타입/문법 결함** | **-15점** | 타입 힌트 불일치, 린트 경고, 정의되지 않은 변수 참조 |
| **코드 가독성 저해** | **-10점** | 함수당 50라인 초과, 3중 초과 들여쓰기(Nested Loops/Ifs), 매직 넘버 사용 |
| **문서 명세 결함** | **-10점** | 마크다운 헤딩 계층 오류, 코드 블록 언어 식별자 태그 누락 |

---

## 3. 합격 기준 (Threshold)
* **총점 90점 이상** 획득
* **감점 항목 2개 이하**일 것
* 하드 게이트 위반 0건일 것
